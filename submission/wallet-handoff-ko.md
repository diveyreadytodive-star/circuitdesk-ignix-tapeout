# CircuitDesk 메인넷 실행 순서

**마감: 2026-10-06 13:00 KST.** 이 문서는 실제 X Layer 메인넷 작업용입니다. 로컬 Anvil 테스트에서 나온 주소는 자금 수신 주소가 아닙니다. **본인이 관리하는 OKX Wallet 또는 MetaMask의 X Layer 주소에만 OKB를 준비하세요.** 개인키와 복구문구는 어디에도 입력하거나 공유하지 마세요.

1. 지갑 확장 프로그램이 활성화된 **일반 Chrome 브라우저**에서 [CircuitDesk](https://diveyreadytodive-star.github.io/circuitdesk-ignix-tapeout/)를 엽니다. Codex의 내장 브라우저와 이번에 검사한 Chrome 자동화 탭에서는 지갑 제공자가 보이지 않았습니다. `Connect wallet`에 지갑 오류가 나오면 확장 프로그램이 활성화된 브라우저 프로필로 다시 여세요.
2. 지갑에서 **X Layer 메인넷, 체인 ID 196**과 본인 주소를 확인합니다. 관측한 세 계약 지불액의 합은 **0.008824 OKB + 세 거래의 가스비**입니다. 실제 가용 잔액과 거래별 금액은 서명 직전에 확인하세요.
3. 앱에서 `Connect wallet` → `Create a processor`를 엽니다. 미리 채워진 제안은 `CircuitDesk Logic One`, `CDL1`, 합계 공급 상한 `100000`, 민트 단가 `0.000066 OKB`입니다. 공개되는 이름·스토리·발행 조건을 읽고, 팩토리 주소 `0x1f09daefa827f02cbb40967cc91b259763760761` 및 현재 배포 수수료를 확인한 뒤 **본인이 첫 번째 지갑 거래를 서명**합니다.
4. 거래가 확정되면 프로세서 주소와 **생성 거래 해시**를 복사해 둡니다. 프로세서 카드의 공급 상한·민트 단가·배포 지갑이 입력한 내용과 일치하는지 확인하세요. 다른 주소나 미확인 거래가 표시되면 다음 단계로 넘어가지 마세요.
5. `Review disagreement` XOR 템플릿을 선택하고 새 프로세서의 비용 표를 봅니다. 새 지갑에 NAND가 없다면 **4 NAND 민트**가 필요합니다. 관측 수수료 기준 민트는 `0.000924 OKB + 가스`, 다음 tapeout은 `0.0013 OKB + 가스`입니다. `Tape out on X Layer`를 누르면 **민트와 tapeout을 서로 다른 지갑 거래로 서명**합니다. 민트가 성공하고 tapeout이 실패·취소되면 지불한 NAND는 지갑에 남고 자동 환불되지 않습니다.
6. 완료 화면에서 회로 ID, **tapeout 거래 해시**, `?processor=…&circuit=…&tx=…`가 포함된 앱 주소를 복사합니다. 앱의 `eth_call`로 XOR 입력 `00, 10, 01, 11`의 결과가 각각 `0, 1, 1, 0`인지 확인할 수 있습니다. `eth_call`은 조회라서 새 거래 영수증을 만들지 않습니다.
7. 이 채팅에 **생성 거래 해시와 최종 앱 공유 주소**만 알려주세요. 제가 거래 시각·팩토리 출처·발행 조건·회로를 별도 RPC로 검증하고 README, `readiness.json`, 제출 초안을 갱신합니다. 이후 [촬영 대본](filming-script.md)에 따라 영상을 직접 녹화·공개 업로드하고, [공식 제출폼](https://docs.google.com/forms/d/e/1FAIpQLSd7USjG6LUNNRxwFWY4YEuSY0V0xv8VZNCl6z_-lGSl96vWZA/viewform?usp=dialog)의 연락처를 직접 입력한 뒤 최종 제출합니다.

거래가 **제출됨·미확인·실패** 상태로 남으면 먼저 그 해시를 블록 탐색기에서 확인하세요. 앱은 미확인 해시를 저장해 중복 지불을 막습니다. 이미 지불한 거래를 확인하지 않고 같은 단계를 다시 실행하지 마세요. 공개 팩토리는 업그레이드 가능하며 TapeOut 인터페이스는 현재 X Layer 계약을 미봉인·미감사 테스트 단계로 설명합니다.
